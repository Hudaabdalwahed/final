# Flower Shop 🌸

A polished Vue 3 + TypeScript flower shop frontend built with Composition API, Pinia, Vue Router and Bootstrap.

## Included
- Elegant responsive storefront and editorial home page
- Product search, price filters and sorting
- Product details, cart, checkout and order confirmation
- Wishlist, profile and order history
- Login / Register with protected routes
- Admin dashboard
- Lazy-loaded routes
- Pinia stores for cart, auth, wishlist and orders
- Custom `v-focus` directive
- `provide / inject`, lifecycle hooks, `computed`, `watch`, `reactive`, `ref`, props and emits examples
- API service structure ready for Django REST API
- Responsive mobile navigation and polished footer

## Run
```bash
npm install
npm run serve
```
